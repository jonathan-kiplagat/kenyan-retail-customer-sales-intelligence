# Kenyan Retail Customer & Sales Intelligence

**Data Science and Analytics Capstone: Customer and Sales Intelligence for a Kenyan Retailer**

This project analyses two years (2024–2025) of sales for *Duka Bora*, a fictional six-store Kenyan supermarket chain. It answers four management questions: who buys what, where and when; which products and stores drive revenue and profit; which customers are drifting away; and what demand to expect next month.

> **Data notice:** all retail records (transactions, customers, products, brands, prices) are **synthetic**, generated by a seeded, documented script. The only real-world data is the verified Kenyan public-holiday calendar.

## Dataset at a glance

| Table | Rows | Notes |
|---|---|---|
| `sales_transactions` | **3,000** (raw) | One product line per receipt; includes logged data-quality issues |
| `customers` | 1,800 | No personal identifiers |
| `products` | 40 | 6 categories |
| `stores` | 6 | Nairobi CBD, Westlands, Thika, Mombasa, Kisumu, Nakuru |
| `promotions` | 20 | Category campaigns |
| `calendar` | 731 | Includes payday and public-holiday flags |
| `kenya_public_holidays_2024_2025` | 28 | Public Holidays Act and Kenya Gazette (real) |

## How to reproduce (Windows, VS Code)

Requires Python 3.11 or later; developed on Python 3.14. Run these in a PowerShell terminal opened in the project folder:

```powershell
# 1. Create and activate a virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1
#    If activation is blocked, run once:  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# 2. Install dependencies
pip install -r requirements.txt

# 3. Regenerate the raw data (identical output every time, seed 2024)
python -m src.data_generation.generate_data

# 4. Run the quality checks
python -m pytest -q

# 5. Open the notebooks (or open them in VS Code and pick the .venv kernel)
jupyter notebook notebooks/
```

All paths are relative to the project root (`src/config.py`), so the project runs on any machine without edits.
